이게 뭔가요?

앱 1편에서 만든 타이머는 아직 내 컴퓨터 안에만 있어요. 이번 편에서는 인터넷에 올려서 휴대폰 홈 화면에 앱처럼 설치하고, 주소를 알려 주면 누구나 쓸 수 있게 해요. 비용은 무료예요.

낱말뜻
PWA (설치형 웹앱)홈 화면에 추가하면 이름·아이콘과 함께 앱처럼 열리는 웹앱
manifest앱 이름·아이콘·색을 적어 두는 작은 파일. 이게 있어야 앱처럼 설치돼요
GitHub PagesGitHub 저장소의 파일을 무료 웹사이트로 보여 주는 기능

GitHub가 처음이라면 GitHub 한눈에 보기를 먼저 읽어 보세요.

0. 먼저 준비할 것

  • 앱 1편에서 만든 타이머 폴더
  • GitHub 계정 — 없다면 휴대폰 2편의 가입 방법을 보세요
  • 휴대폰 (안드로이드 크롬 또는 아이폰 사파리)

1. 홈 화면에 어울리게 꾸미기

Code 탭에서 앱 1의 대화를 이어 가거나, 연습 폴더로 새 대화를 열고 보내세요.

따라 입력해 보세요
타이머 폴더의 웹앱을 휴대폰 홈 화면에 추가했을 때 앱처럼 열리게 해줘. 앱 이름은 '운동 타이머', 파란 바탕에 시계 모양 아이콘(PNG)과 manifest 파일도 만들어줘

파일 만들기 카드를 보고 허용하세요. 타이머 폴더에 manifest 파일과 아이콘 그림이 생기면 성공이에요. PNG를 만들려고 프로그램 설치를 물어볼 수도 있는데, 무엇을 설치하는지 보고 허락하면 돼요.

2. GitHub에 공개 저장소를 만들고 파일 올리기

  1. github.com → 오른쪽 위 + → New repository.
  2. 이름: timer · Public(공개) · Add a README file 체크 → Create repository.
  3. 저장소 화면에서 Add file → Upload files.
  4. 컴퓨터의 타이머 폴더를 열고, 안의 파일을 모두 선택해서 끌어다 놓습니다.
  5. 아래 Commit changes.
이번에는 Public(공개)이에요 — 무료로 웹 주소를 받으려면 공개 저장소여야 해요. 그래서 누구나 파일 내용을 볼 수 있어요. 이름·전화번호·비밀번호·API 키 같은 건 절대 넣지 마세요.

3. GitHub Pages 켜서 내 앱 주소 받기

  1. timer 저장소 → Settings → 왼쪽 Pages.
  2. Source: Deploy from a branch · Branch: main · / (root) → Save.
  3. 1~2분 뒤 새로고침하면 Your site is live at https://아이디.github.io/timer/가 나와요.

4. 휴대폰 홈 화면에 설치하기

휴대폰 브라우저로 내 앱 주소를 여세요. 카카오톡 '나와의 채팅' 같은 곳에 주소를 보내 두면 편해요.

  • 안드로이드(크롬): 오른쪽 위 ⋮ → 홈 화면에 추가(또는 앱 설치).
  • 아이폰(사파리): 아래 공유(□↑) → 홈 화면에 추가.

5. 고칠 때는 이렇게

  1. 컴퓨터의 Claude에게 고칠 점을 말하고 허용합니다.
  2. 바뀐 파일을 timer 저장소에 다시 Upload files. 같은 이름이면 새 파일로 바뀌어요.
  3. 1~2분 뒤 휴대폰 앱을 닫았다 열면 반영돼요.

익숙해지면 휴대폰 3편처럼 Claude가 timer 저장소에서 직접 고치고 PR → 병합하게 할 수도 있어요.

잘 안 될 때

이런 경우이렇게 하세요
주소가 404예요저장소 첫 화면에 index.html이 바로 있는지 보세요. 폴더째 올렸다면 폴더 안 파일만 다시 올리세요.
Pages에 업그레이드 안내가 나와요저장소가 Private이에요. Settings 맨 아래 Change visibility → Public.
아이폰에 '홈 화면에 추가'가 없어요사파리에서만 돼요.
아이콘이 글자로 나와요Claude에게 "아이폰 홈 화면 아이콘(apple-touch-icon)도 넣어줘"라고 한 뒤 다시 올리세요.

조심할 점

  • 공개 저장소: 올린 파일은 누구나 볼 수 있어요. 개인정보·비밀번호·API 키 금지.
  • 기록은 각자 휴대폰에: 기록 기능을 넣어도 쓰는 사람 휴대폰 브라우저에만 저장돼요.
  • 남의 것 베끼지 않기: 다른 앱의 이름·그림·음악을 그대로 쓰지 마세요.

오늘 배운 것

  • GitHub Pages로 저장소 파일을 무료 웹사이트로 만든다. 공개라서 누구나 볼 수 있다.
  • manifest + 아이콘이 있으면 홈 화면에 앱처럼 설치된다.
  • 고칠 때는 Claude로 고치고 → 다시 올리기.

컴퓨터 없이 휴대폰만으로 만드는 방법은 앱 3편에서, 안드로이드 앱(APK)은 앱 4편에서 다뤄요.

* The pictures are drawn examples to make the steps easy to follow. Real screens may look slightly different.

What is this?

The timer from App guide 1 still lives only on your computer. In this guide you'll put it online, install it like an app on your phone's home screen, and share an address anyone can use. It's free.

WordMeaning
PWA (installable web app)A web app that opens like an app, with its name and icon, once added to the home screen
manifestA small file listing the app's name, icon and colors. It's what makes it installable
GitHub PagesA feature that serves a GitHub repository's files as a free website

New to GitHub? Read GitHub at a glance first.

0. What you need

  • The timer folder from App guide 1
  • A GitHub account — if you don't have one, see how to sign up in Phone guide 2
  • A phone (Chrome on Android or Safari on iPhone)

1. Make it fit the home screen

In the Code tab, continue the App 1 chat, or open a new chat with the Practice folder and send this.

Type this
Make the web app in the timer folder open like an app when added to a phone's home screen. Name it 'Workout timer', and create a stopwatch icon on a blue background (PNG) and a manifest file

Check the create-file cards and click Allow. You're done when a manifest file and an icon image appear in the timer folder. To make a PNG it may ask to install a tool; check what it installs and allow it.

2. Make a public repository on GitHub and upload

  1. github.com → + at the top right → New repository.
  2. Name: timer · Public · tick Add a README file → Create repository.
  3. On the repository page: Add file → Upload files.
  4. On your computer, open the timer folder and select all the files inside, then drag them in.
  5. Click Commit changes at the bottom.
This time it's Public — a free web address needs a public repository, so anyone can read the files. Never put names, phone numbers, passwords or API keys in it.

3. Turn on GitHub Pages and get your app's address

  1. timer repository → Settings → Pages on the left.
  2. Source: Deploy from a branch · Branch: main · / (root) → Save.
  3. After 1–2 minutes, refresh: Your site is live at https://your-id.github.io/timer/ appears.

4. Install it on your phone's home screen

Open your app's address in your phone's browser. Sending it to yourself in a message makes this easy.

  • Android (Chrome): ⋮ at the top right → Add to Home screen (or Install app).
  • iPhone (Safari): Share (□↑) at the bottom → Add to Home Screen.

5. How to update

  1. Tell Claude on your computer what to change, and allow it.
  2. Upload files again to the timer repository. Same-named files are replaced.
  3. After 1–2 minutes, close and reopen the app on your phone.

Once you're comfortable, you can have Claude edit the timer repository directly and merge via a PR, like Phone guide 3.

If it doesn't work

If this happensDo this
The address gives a 404Check index.html sits right on the repository's front page. If you uploaded the folder itself, upload just the files inside.
Pages shows an upgrade noticeThe repository is Private. Settings → bottom Change visibility → Public.
No 'Add to Home Screen' on iPhoneIt only works in Safari.
The icon shows a letterAsk Claude "Add an iPhone home screen icon (apple-touch-icon) too", then upload again.

Be careful

  • Public repository: anyone can read what you upload. No personal data, passwords or API keys.
  • Records stay on each phone: a history feature saves only in each user's phone browser.
  • Don't copy others: don't reuse another app's name, pictures or music.

What you learned today

  • GitHub Pages turns repository files into a free website. It's public, so anyone can see it.
  • With a manifest and icon, it installs on the home screen like an app.
  • To update: change it with Claude → upload again.

Building with just your phone, no computer, is App guide 3; an Android app (APK) is App guide 4.
