완료진행 중아직준비 중

터미널 과정(CLI · 심화) — 검은 글자 창(PowerShell·터미널)에서 쓰는 방법이에요. 처음이라면 버튼만 누르면 되는 데스크톱 과정부터 보세요.

👆 이 내용은 버튼 따라 하는 실습으로도 있어요. 처음이라면 실습으로 직접 해 보고, 이 글은 복습할 때 보세요. 실습 시작하기 →

※ 글 속 그림은 따라 하기 쉽도록 그린 예시입니다. 실제 화면과 모양이 조금 다를 수 있어요.

시작하기 전에 — 1편~3편을 따라 해서 바탕화면에 연습 폴더가 있어야 합니다. 오늘도 꼭 연습 폴더 안에서만 해 주세요.

오늘 새로 배우는 것

  1. 파일 여러 개를 한 번에 만들게 하기
  2. 폴더를 만들고, 파일을 옮기고, 이름을 바꾸게 하기
  3. 새로운 허락 화면 "명령을 실행해도 될까요?" 읽는 법

먼저 알아 두기 — "명령"이 뭔가요?

지금까지 Claude는 파일의 내용을 만들고 고쳤어요. 그때는 Create file / Edit file 허락 화면이 나왔죠.

폴더를 만들거나 파일을 옮기는 일은 조금 달라요. Claude가 컴퓨터에게 짧은 영어 지시문(명령)을 내려서 처리해요. 1편에서 우리가 설치 명령을 붙여 넣었던 것과 같은 종류예요. 그래서 이번에는 Bash command라는 다른 모양의 허락 화면이 나와요.

1. Claude Code 켜기

1~3편과 같습니다. 연습 폴더에서 창을 열고 claude 를 입력하고 Enter. 새로운 일이니 이어 하기(-c) 없이 그냥 켜면 돼요.

2. 메모 파일 3개 한 번에 만들기

따라 입력해 보세요
회의.txt, 장보기.txt, 아이디어.txt 메모 파일 3개를 만들고 내용은 예시로 한두 줄씩 적어줘

1편처럼 Create file 허락 화면이 파일마다 한 번씩, 세 번 나와요. 파일 이름을 확인하고 매번 1. Yes 에서 Enter.

3. 폴더를 만들고 파일 옮기기

따라 입력해 보세요
메모 폴더를 만들고 방금 만든 세 파일을 그 안으로 옮겨줘

이번에는 처음 보는 허락 화면이 나와요.

4. "명령을 실행해도 될까요?" 화면 읽는 법

보이는 것뜻
Bash command"컴퓨터에 명령을 내려도 될까요?"라는 허락 화면이에요.
가운데 영어 한 줄실제로 실행할 명령이에요. 예) mkdir = 폴더 만들기, mv = 옮기기·이름 바꾸기
그 아래 회색 글Claude가 적은 설명이에요. 무엇을 하려는지 여기서 확인하세요.
1. Yes네, 실행하세요.
2. Yes, and don't ask again…이런 종류의 명령은 다시 묻지 말고 실행하세요.
→ 지금은 고르지 마세요.
3. No…아니요, 다르게 해 주세요.

명령의 모양은 컴퓨터마다 조금 다를 수 있어요. Windows에서는 New-Item, Move-Item 처럼 보이기도 해요. 영어 명령을 몰라도 괜찮아요. 회색 설명이 내가 부탁한 내용과 맞는지만 보면 돼요.

이런 명령이 보이면 멈추세요 — rm, del, Remove-Item 은 지우는 명령이에요. 지우라고 부탁하지 않았는데 이런 말이 보이면 3. No 를 고르세요.

설명이 "메모 폴더를 만들고 파일 3개를 옮긴다"는 내용이면 1. Yes 에서 Enter. 명령이 여러 개면 허락을 여러 번 물을 수 있어요. 매번 읽고 Yes를 고르세요.

5. 파일 이름 한꺼번에 바꾸기

따라 입력해 보세요
메모 폴더 안 파일 이름 앞에 오늘 날짜를 붙여줘. 예) 2026-11-15_회의.txt

다시 Bash command 허락 화면이 나와요. 설명을 읽고 맞으면 1. Yes. 날짜는 실제로 오늘 날짜로 붙어요.

6. 결과 눈으로 확인하기

연습 폴더를 열면 메모 폴더가 생겨 있어요. 두 번 눌러 열어 보세요.

파일 3개가 들어 있고, 이름 앞에 날짜가 붙어 있으면 성공이에요. 손으로 했다면 파일을 하나씩 옮기고 이름을 고쳐야 했을 일을 말 두 마디로 끝냈어요.

잘 안 될 때

이런 경우이렇게 하세요
허락을 여러 번 물어요정상이에요. 명령이나 파일마다 한 번씩 물어요.
지우는 명령(rm, del…)이 보여요지우라고 하지 않았다면 3. No 를 고르고, 원하는 것을 다시 말해 주세요.
잘못 옮기거나 이름이 이상해졌어요Claude에게 "방금 한 거 원래대로 되돌려줘"라고 말하세요.
폴더가 안 보여요폴더 창을 닫았다가 다시 열어 보세요.

오늘 배운 것

  • 여러 파일도 한 문장으로 한꺼번에 만들고, 옮기고, 이름을 바꿀 수 있다.
  • 폴더·옮기기·이름 바꾸기는 Bash command(명령 실행) 허락을 받는다.
  • 명령을 몰라도 회색 설명을 읽으면 된다. 지우는 명령은 특히 조심한다.

다음 글에서는 매번 묻는 허락 방식(모드)을 바꾸는 법과, 언제 바꿔도 되는지를 배웁니다.

※ The pictures in this guide are illustrations to make it easy to follow. Your screen may look a little different.

Before you start — follow Guide 1 to Guide 3 so there's a Practice folder on your desktop. Today too, please work only inside the practice folder.

What you'll learn today

  1. Have it create several files at once
  2. Have it make a folder, move files and rename them
  3. How to read a new permission screen: "May I run this command?"

First — what is a "command"?

So far, Claude has created and edited the contents of files. Each time, you saw a Create file / Edit file permission screen.

Making folders and moving files is a little different. Claude does it by giving the computer a short instruction in English (a command), the same kind of thing as the install command you pasted in Guide 1. So this time you'll see a different permission screen called Bash command.

1. Start Claude Code

Same as Guides 1–3. Open the window in the practice folder, type claude and press Enter. It's a new task, so just start it normally, without -c.

2. Create three memo files at once

Type this
Create three memo files, meeting.txt, groceries.txt and ideas.txt, each with a line or two of example text

As in Guide 1, a Create file permission screen appears once for each file, three times. Check the file name and press Enter on 1. Yes each time.

3. Make a folder and move the files

Type this
Make a memos folder and move the three files you just made into it

This time you'll see a permission screen you haven't seen before.

4. How to read the "May I run this command?" screen

What you seeMeaning
Bash commandA permission screen asking "May I give your computer a command?"
The line in the middleThe actual command it will run. e.g. mkdir = make a folder, mv = move or rename
The gray text belowClaude's description of what it's about to do. Check it here.
1. YesYes, run it.
2. Yes, and don't ask again…Run commands like this without asking again.
→ Don't choose this for now.
3. No…No, do it differently.

Commands can look a little different on each computer. On Windows you may see things like New-Item or Move-Item. You don't need to know the commands: just check that the gray description matches what you asked for.

Stop if you see these — rm, del and Remove-Item are commands that delete. If you didn't ask to delete anything and you see one of these, choose 3. No.

If the description says it will make a memos folder and move the three files, press Enter on 1. Yes. If there are several commands, it may ask several times. Read and choose Yes each time.

5. Rename several files at once

Type this
Add today's date to the front of each file name in the memos folder, e.g. 2026-11-15_meeting.txt

The Bash command screen appears again. Read the description and choose 1. Yes if it's right. The date added will be today's actual date.

6. See the result with your own eyes

Open the practice folder and you'll see a new memos folder. Double-click to open it.

If the three files are there with the date in front of their names, it worked. What would have taken moving and renaming files one by one by hand, you finished with two sentences.

If something goes wrong

If this happensDo this
It asks for permission many timesThat's normal. It asks once for each command or file.
You see a delete command (rm, del…)If you didn't ask to delete, choose 3. No and say again what you want.
Something was moved or renamed wronglyTell Claude, "Undo what you just did."
You can't see the folderClose the folder window and open it again.

What you learned today

  • You can create, move and rename many files at once with one sentence.
  • Making folders, moving and renaming ask for Bash command (run a command) permission.
  • You don't need to know the commands: read the gray description. Be especially careful with delete commands.

In the next guide you'll learn how to change the permission mode (how often it asks), and when it's okay to change it.
