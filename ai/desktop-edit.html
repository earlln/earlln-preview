※ 글 속 그림은 따라 하기 쉽도록 그린 예시입니다. 실제 앱 화면과 모양·글자가 조금 다를 수 있어요.

시작하기 전에 — 데스크톱 1편을 따라 해서 바탕화면 연습 폴더에 할일.txt가 있어야 합니다.

오늘 새로 배우는 것

  1. Claude가 파일을 고치기 전에 보여 주는 "바뀌는 내용" 읽는 법
  2. 마음에 안 들 때 거절하고 다시 부탁하는 법
  3. 끝난 뒤 Changes에서 바뀐 내용을 다시 보는 법

1. 앱 열고 연습 폴더로 시작하기

  1. Claude 앱을 열고 왼쪽 위 Code 탭을 누릅니다.
  2. 왼쪽 위 + New를 눌러 새 대화를 엽니다.
  3. 입력 칸 아래가 Local, 폴더가 연습인지 확인합니다. 아니라면 1편 6번처럼 Open folder…로 연습 폴더를 고르세요. (한 번 고른 폴더는 다음부터 목록에 보여요)
  4. 허락 방식이 Manual인지도 확인하세요.

2. 먼저 파일을 읽어 달라고 하기

따라 입력해 보세요
할일.txt에 뭐라고 적혀 있는지 보여줘

Claude가 파일 내용을 보여 줍니다. 이번에는 허락을 묻지 않았죠? 파일을 읽기만 할 때는 아무것도 바뀌지 않아서 바로 보여 줘요. 만들거나 고칠 때만 허락을 물어요.

3. 고쳐 달라고 하기

따라 입력해 보세요
할일.txt의 두 번째 줄을 "점심 약속 잡기"로 바꿔줘

1편처럼 허락 카드가 나오는데, 이번에는 무엇이 어떻게 바뀌는지를 함께 보여 줘요.

4. "바뀌는 내용" 읽는 법

보이는 것뜻
- 빨간 줄지워질 내용
+ 초록 줄새로 들어갈 내용
색 없는 줄그대로 남는 내용
허용 버튼네, 이대로 고쳐 주세요
거절 버튼아니요, 고치지 마세요 (6번에서 연습해요)

빨간 줄에 원래 두 번째 줄, 초록 줄에 점심 약속 잡기가 보이면 부탁한 대로예요. 허용을 누르세요.

버튼 이름은 Allow·Accept·Deny·Reject 같은 영어로 보일 수 있어요. 허락하는 쪽은 보통 파란색이에요.

5. 결과 눈으로 확인하기

  1. 연습 폴더에서 할일.txt를 두 번 누릅니다. 메모장(Mac은 텍스트 편집기)이 열려요.
  2. 두 번째 줄이 점심 약속 잡기로 바뀌었는지 봅니다.
  3. 확인했으면 메모장은 닫아 주세요.

6. 마음에 안 들 때 — 거절하고 다시 부탁하기

이번에는 일부러 거절해 봅니다. 거절해도 파일은 전혀 바뀌지 않으니 안심하세요.

따라 입력해 보세요
할일 목록 맨 위에 제목을 하나 붙여줘
  1. Claude가 정한 제목이 허락 카드에 보이면, 거절 버튼을 누릅니다.
  2. 입력 칸에 원하는 것을 다시 적고 Enter.
이렇게 다시 부탁해 보세요
제목은 "오늘의 할 일"로 해줘

새 허락 카드에 + 오늘의 할 일이 초록 줄로 보이면 허용.

7. 바뀐 내용 다시 보기 — Changes

대화가 길어져서 무엇이 바뀌었는지 헷갈리면, 화면 오른쪽의 Changes(바뀐 파일 목록)를 보세요. +1 -1 같은 숫자를 누르면 바뀐 줄을 빨강·초록으로 다시 보여 줘요.

Changes가 안 보이면 화면 오른쪽 위의 패널 버튼이나 메뉴에서 Changes를 찾아보세요.

잘 안 될 때

이런 경우이렇게 하세요
"할일.txt가 없다"고 함입력 칸 아래 폴더가 연습인지 확인하세요.
허락을 안 묻고 바로 고쳐요허락 방식이 Manual이 아닐 수 있어요. Manual로 바꾸세요.
실수로 허용을 눌렀어요Claude에게 "방금 바꾼 거 원래대로 돌려줘"라고 말하면 됩니다.

오늘 배운 것

  • 읽을 때는 허락을 묻지 않고, 만들거나 고칠 때만 묻는다.
  • 허락 카드에서 빨간 줄은 지워질 내용, 초록 줄은 새로 들어갈 내용이다.
  • 마음에 안 들면 거절하고 다시 말하면 된다. 파일은 그대로다.
  • 끝난 뒤에는 Changes에서 바뀐 내용을 다시 볼 수 있다.

터미널에서 같은 내용을 배우고 싶다면 터미널 과정 2편을 보세요.

다음 글에서는 대화를 새로 시작하고, 예전 대화를 이어서 하는 법을 배웁니다.

※ The pictures in this guide are illustrations to make it easy to follow. The real app may look a little different or use different words.

Before you start — follow Desktop guide 1 so that todo.txt is in the Practice folder on your desktop.

What you'll learn today

  1. How to read the "what will change" view Claude shows before editing a file
  2. How to decline and ask again when you don't like it
  3. How to look at changes again afterwards in Changes

1. Open the app and start in the practice folder

  1. Open the Claude app and click the Code tab at the top left.
  2. Click + New at the top left to start a new conversation.
  3. Check that the buttons under the typing box show Local and the Practice folder. If not, choose the practice folder with Open folder… as in step 6 of guide 1. (Once chosen, it appears in the list next time.)
  4. Also check that the permission mode is Manual.

2. First, ask it to read the file

Type this
Show me what todo.txt says

Claude shows what's in the file. Notice it didn't ask permission? When it only reads a file, nothing changes, so it just shows you. It only asks when it creates or edits something.

3. Ask it to make an edit

Type this
In todo.txt, change line 2 to "Set up a lunch meeting"

As in guide 1, a permission card appears, but this time it also shows exactly what will change.

4. How to read "what will change"

What you seeMeaning
- Red lineText that will be removed
+ Green lineText that will be added
Uncolored lineText that stays the same
Allow buttonYes, make this change
Deny buttonNo, don't change it (you'll practice this in step 6)

If the red line shows the old line 2 and the green line shows Set up a lunch meeting, it's what you asked for. Click Allow.

The buttons may be labeled Allow, Accept, Deny, Reject and so on. The one that gives permission is usually blue.

5. See the result with your own eyes

  1. In the practice folder, double-click todo.txt. Notepad (TextEdit on a Mac) opens.
  2. Check that line 2 now says Set up a lunch meeting.
  3. Once you've checked, close Notepad.

6. Don't like it? Decline and ask again

This time, decline on purpose. Declining doesn't change the file at all, so don't worry.

Type this
Add a title at the top of the to-do list
  1. When the permission card shows the title Claude chose, click Deny.
  2. Type what you want instead and press Enter.
Ask again like this
Make the title "Today's to-dos"

When the new card shows + Today's to-dos as a green line, click Allow.

7. Look at the changes again — Changes

If the conversation gets long and you lose track of what changed, look at Changes (the list of changed files) on the right of the screen. Click numbers like +1 -1 to see the changed lines again in red and green.

Can't see Changes? Look for a panel button at the top right of the screen, or Changes in the menu.

If something goes wrong

If this happensDo this
It says todo.txt doesn't existCheck that the folder under the typing box is Practice.
It edits without askingThe permission mode may not be Manual. Switch it to Manual.
You clicked Allow by mistakeTell Claude, "Undo the change you just made."

What you learned today

  • It doesn't ask when it reads; it only asks when it creates or edits.
  • On the permission card, red lines will be removed and green lines will be added.
  • If you don't like it, Deny and say it again. The file stays as it was.
  • Afterwards, you can see the changes again in Changes.
